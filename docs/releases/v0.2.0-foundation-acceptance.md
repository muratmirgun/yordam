## Final review blocker closure

One final review identified four release blockers. Source commit `860b9b0068b19ce379af1dfc30c1710f98537081` retains all four closures; no subsequent code review was requested or run.

### 1. Production ApplicationService/LegacyAdapter wiring and exact-cursor E2E

`TestProductionLegacyCommandUsesApplicationProtocolAndRealCursorProjection` passed through the complete regular and race suites and both Foundation acceptance commands. It bootstrapped the production runtime, made direct legacy `Runtime.RunTurn` use fail deliberately, routed a mode change and tool-using turn through the application protocol, checked canonical workspace-control and session journals, projected current state from real journals, proved an old exact cursor did not observe later state, and compared TUI, LegacyAdapter, and JSON/headless durable semantics. Both Foundation logs recorded `source=production_journals cursor=exact`.

### 2. RunControl ownership for mode, model, and trusted-shell changes

The RunControl closure set passed through the complete regular and race suites:

- `TestRunControlCommitsSessionSettingOnlyInsideAuthorizedDispatch` proved the consequential setting commit occurs only inside authorized dispatch and returns the exact workspace/session cursor vector;
- `TestRunControlCancelledSettingDispatchDoesNotCommitSessionSetting` proved cancellation commits no setting;
- `TestRunControlSettingTerminalFailureDoesNotRepeatCommittedSetting` proved terminal recovery does not repeat the consequence or dispatch;
- `TestCommitSessionChangeAllowsOnlyPureTitleMetadata` rejected mode, model, and trusted-shell events from the pure session-change path.

### 3. `commit_unknown` exact transaction lookup and adoption

`TestCommitUnknownResolutionAdoptsProvenCommitForEveryCaller` passed for turn, pure command, pure title, and control callers. Every unknown append was resolved by an exact transaction lookup plus committed-transaction read, and the proven transaction was published without resending the append/effect. `TestCommitUnknownResolutionReturnsTypedUncertaintyWithoutResend` also passed: an unproven transaction produced typed uncertainty after exactly one append and one lookup.

### 4. Transient overflow exactly-once cancellation

`TestTransientOverflowFakeHeadlessCancellationRunsOnceOutsideBrokerLock` passed through the complete regular and race suites. A saturated fake-headless transient stream invoked cancellation exactly once, and the callback safely re-entered `Broker.Epoch`, proving it ran outside the broker lock rather than deadlocking.
