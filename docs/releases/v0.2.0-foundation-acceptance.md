## Architecture boundary review

The source-parser boundary gate passed with `parser_append_calls=1`, `parser_storage_calls=2`, and `parser_dispatch_calls=6` under independent allowlists.

- Turn-journal `AppendBatch` ownership is restricted to `internal/orchestrator`.
- Storage encoding and writes are restricted to `internal/session/jsonl`.
- Provider `Stream` and effect-capable `Execute` calls are restricted to the orchestrator-facing provider/tool dispatch services invoked by `internal/orchestrator`.
- `internal/app`, compatibility adapters, and other bounded services do not cross either direct effect boundary.
- The legacy monolithic `agent.Runner` is absent.
- Bounded services expose no journal append method.
- Runtime composition uses only the orchestrated runner; consequential control events commit inside the dispatch callback; the operation lane serializes consequential turns and controls across sessions.

Traceability: PRD-FR-03; Capability Contract 4.1-4.3; Foundation 12.1-12.3; Acceptance 6.4.
